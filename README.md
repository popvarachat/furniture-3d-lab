# Furniture 3D Lab

**Fork → run → adapt your furniture.** เว็บทดลอง Furniture 3D ภาษาไทย พร้อมตัวอย่าง 6 แบบ ใช้ Three.js + Vite

## เริ่มใช้งาน

ต้องมี Node.js 20.19+ หรือ LTS ใหม่กว่า, npm และ browser ที่รองรับ WebGL2
กด **Fork** ด้านบนก่อน แล้ว clone repo ของคุณ หรือทดลองต้นฉบับ:

```sh
git clone https://github.com/popvarachat/furniture-3d-lab.git
cd furniture-3d-lab
npm ci
npm run dev
```

เปิด http://127.0.0.1:5187

```sh
npm run check
npm run build
npm run preview
```

## ทำอะไรได้

เลือกสินค้า • หมุน/ซูม • มุมหน้า/ข้าง/บน • แยก–ประกอบชิ้นส่วน • คลิกดูวัสดุ • ทดลองสีไม้ • โครงเส้น • หมุนอัตโนมัติ • บันทึก PNG • รองรับมือถือ

## ตัวอย่าง

| รหัส | Furniture | W × D × H (mm) |
|---|---|---|
| DEMO-01 | Round coffee table | 950 × 950 × 720 |
| DEMO-02 | Luggage rack | 1500 × 575 × 750 |
| DEMO-03 | Daybed | 1975 × 975 × 775 |
| DEMO-04 | Rectangular coffee table | 1100 × 750 × 400 |
| DEMO-05 | Side table | 550 × 550 × 450 |
| DEMO-06 | Window seat | 3900 × 700 × 695 |

ตัวอย่างเป็นโมเดล procedural ที่ประมาณจากภาพอ้างอิง และเผยแพร่ตามคำขอเจ้าของงาน ไม่รวมภาพแบบต้นฉบับ ชื่อลูกค้า/โครงการ หรือเลขแบบเดิม

**ข้อจำกัด:** ตัวอย่างปรับสเกลกรอบโมเดลให้ตรงกับมิติที่กรอก (envelope fitting) จึงไม่ใช่การยืนยันมิติรายชิ้น ความโค้ง เบาะ รอยต่อ จุดยึด และโครงซ่อนยังเป็นการประมาณ ห้ามใช้เป็น CAD ผลิต BOM แผนตัด หรือลำดับประกอบที่ผ่านการตรวจรับ

## ให้ทีมเพิ่มแบบใหม่

1. อ่าน [Prompt พร้อมใช้](prompts/BUILD_FURNITURE_TH.md)
2. เก็บแบบที่มีสิทธิ์ใช้ใน local folder `private-inputs/` ซึ่ง Git ไม่ติดตาม
3. กรอก [ตารางมิติและความไม่แน่นอน](docs/DIMENSION_RECORD.example.json)
4. ทำตาม [คู่มือเพิ่มโมเดล](docs/ADDING_A_MODEL.md)
5. ตรวจภาพ มิติ และปุ่มก่อนส่งงาน

## โครงสร้าง

- `src/app.js` — UI, แยกชิ้นส่วน, เลือกวัสดุ และกล้อง
- `src/viewer.js` — renderer / orbit / label adapter ที่เขียนใหม่
- `src/products/models.js` — catalog และตัวสร้างโมเดลทั้ง 6
- `src/style.css` — responsive UI
- `prompts/` — Prompt สำหรับให้ AI ช่วยเพิ่มสินค้า
- `docs/` — คู่มือ มิติ และข้อจำกัดการตรวจ
- `scripts/` — source checks รวมการตรวจ UTF-8 และภาษาเพี้ยน
- `docs/ci.example.yml` — ตัวอย่าง GitHub Actions สำหรับ npm ci, check และ build; คัดลอกไป `.github/workflows/ci.yml` เพื่อเปิดใช้

## โหมดสร้างโฆษณาและร่างอีเมล

1. เลือกสินค้า แล้วกด **สร้างโฆษณา + อีเมล** บนแถบด้านบน
2. กรอกแบรนด์ หัวข้อ ข้อความ ราคา/ข้อเสนอ และช่องทางติดต่อ
3. กดสร้างภาพและข้อความ ได้โปสเตอร์ PNG ขนาด 1200 × 1500 px
4. กรอกอีเมลผู้รับแต่ละครั้ง ตรวจ/แก้หัวเรื่องและข้อความ
5. เลือกเปิดร่างในแอปอีเมล (ข้อความเท่านั้น ต้องแนบ PNG เอง) หรือดาวน์โหลดร่าง **.eml** ที่แนบภาพแล้ว เปิดด้วยโปรแกรมที่รองรับ

ไม่มีการส่งอีเมลอัตโนมัติ ผู้ใช้เป็นคนตรวจและกดส่งเอง ไม่ต้องตั้ง API key หรือ SMTP บนเว็บสาธารณะ การสร้างข้อความเป็น template ที่แก้ไขได้ ไม่เรียก AI ภายนอก ราคาหรือข้อเสนอจะใช้เฉพาะที่กรอก
ความสามารถเปิด/แก้ไฟล์ .eml แตกต่างกันตามโปรแกรมอีเมล หากเปิดเป็นข้อความที่แก้ไม่ได้ ให้ใช้ปุ่มเปิดร่างและแนบ PNG เอง
ทดสอบด้วย `npm test` สำหรับ MIME/ภาษาไทย/ผู้รับ/การเข้ารหัส mailto

## เลือกบรรยากาศด้านหลังโฆษณา

ในโหมดสร้างโฆษณา เลือกช่อง **บรรยากาศด้านหลัง** แล้วกดสร้างภาพใหม่ มี 5 ฉาก 3D ในเครื่อง:

| บรรยากาศ | ตัวอย่างสินค้าที่แนะนำ |
|---|---|
| สตูดิโอเรียบ | ทุกสินค้า เน้นตัวผลิตภัณฑ์ |
| ห้องนั่งเล่นอบอุ่น | โต๊ะกลาง โต๊ะสี่เหลี่ยม |
| ล็อบบี้โรงแรม | Luggage Rack, Side Table |
| มุมหน้าต่างรับแสง | Daybed, Window Seat |
| ระเบียงสวน | ฉากตกแต่งเพิ่มเติม ไม่ยืนยันความเหมาะสมใช้งานกลางแจ้ง |

ระบบแนะนำฉากเริ่มต้นตามสินค้า ผู้ใช้เปลี่ยนได้ ฉากเป็นภาพจำลองด้วย Three.js ไม่ใช่ภาพถ่ายหรือ AI photorealistic ไม่มีการดาวน์โหลดภาพจากบริการอื่น
PNG และภาพแนบใน .eml ใช้ฉากที่เลือก เมื่อเปลี่ยนฉาก ปุ่มดาวน์โหลดจะรอให้สร้างภาพใหม่เพื่อไม่ส่งภาพเก่า

## ภาพโฆษณาสมจริงและความถูกต้องของสเกล

เลือกแหล่งภาพ **นำเข้าภาพถ่าย / ภาพเรนเดอร์สมจริง** แล้วเลือก PNG/JPEG/WebP ของสินค้านั้น ระบบจัดวางภาพโดยรักษาอัตราส่วน ไม่ยืดรูป และใช้ภาพนี้กับ PNG / ร่างอีเมล

ปุ่ม **ดาวน์โหลดขนาดอ้างอิง + Brief เรนเดอร์** ส่งออก JSON ที่ระบุมิติหลัก ข้อสมมติ และข้อจำกัดจากแบบ raster ให้ทีมเรนเดอร์ใช้ต่อ ไม่ใช่เอกสารรับรองมิติ

โหมดนี้ยังไม่ได้สร้างภาพ photorealistic ด้วย AI ภายในเว็บอัตโนมัติ ต้องนำเข้าภาพที่มีอยู่แล้ว ภาพ AI อาจสวยแต่ไม่รับรองรูปทรง/สเกล ต้องใช้ CAD ที่อนุมัติแล้ว สร้างฉากหน่วยจริง ล็อก geometry และกำหนด PBR materials / texture scale / กล้อง / แสง จึงจะตรวจความถูกต้องทางมิติได้

### ตัวอย่างภาพสมจริงพร้อมดู

กด **ดูตัวอย่างภาพสมจริง** บนแถบด้านบน หรือเปิด `/?example=daybed` ระบบจะเลือก Daybed โหลดภาพ AI ตัวอย่าง และจัดเป็นร่างโฆษณาให้ทันที ภาพนี้แสดงแนวคุณภาพภาพ ไม่รับรองรูปทรงหรือมิติจาก CAD ทุกจุด ไม่มีการเรียก AI เพิ่มเมื่อกดปุ่มนี้

### ภาพสมจริงแยกตามสินค้า

ภาพสมจริงมีครบทั้ง 6 รุ่น เลือกสินค้าในเมนูซ้าย แล้วกด **ภาพสมจริงของสินค้านี้** ระบบจะแสดงเฉพาะรุ่นนั้น ไม่เปิดแกลเลอรีรวม
ในหน้าโฆษณาเปลี่ยนรุ่นผ่านช่อง **เลือกสินค้า** ได้ ภาพจะเปลี่ยนตามรุ่นที่เลือก
ลิงก์ตรงใช้ ?example=round950, luggage, daybed, rect1100, side550 หรือ window
ทดสอบด้วย node scripts/photo-qa.cjs บน Windows Chrome และ preview port 5187
