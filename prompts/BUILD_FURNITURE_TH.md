# Prompt: เพิ่ม Furniture จากแบบ 2D
แนบแบบที่คุณมีสิทธิ์ใช้ พร้อมส่งคำสั่งนี้ให้ AI ที่แก้ repo ได้

สร้าง/เพิ่มโมเดล Furniture 3D แบบโต้ตอบได้ใน repo นี้ ใช้ Three.js + Vite และต่อยอด viewer/UI ที่มีอยู่ ลงมือทำจนเปิดใช้ได้ ไม่หยุดแค่เสนอแผน

## 1. อ่านแบบก่อน
- สรุปชื่อสินค้า มิติที่ระบุจริง หน่วย mm และตำแหน่ง/หน้าที่อ้างอิง
- แยก observed / inferred / unknown พร้อมบันทึก assumptions
- ตัวเลขไม่ชัดให้ UNKNOWN ห้ามเดาแล้วแสดงเป็นข้อมูลจริง
- ใช้ตัวเลขกำกับแบบ ไม่วัดสเกลจากภาพแทน

## 2. โมเดล
- ใช้หน่วยเมตรภายใน แบ่งเป็นกลุ่มที่มีชื่อ วัสดุ มิติ และแหล่งอ้างอิง
- ใช้ procedural geometry หรือ CAD/GLB ที่ได้รับอนุญาต
- ไม่สร้างรูเจาะ จุดยึด หรือโครงซ่อนให้ดูเหมือนมีข้อมูลยืนยัน
- มิติที่ทราบต้องสร้างจาก geometry โดยตรง
- ห้ามปรับสเกลทั้งโมเดลเพื่อให้การตรวจผ่านโดยไม่เปิดเผย
- ตัวอย่างเดิมมี envelope fitting: หากคงไว้ให้แสดง scale factors และข้อจำกัด หากต้องตรวจ CAD ให้เลิกใช้ fitting และรายงานส่วนต่างตามจริง
- Exploded view เป็นภาพอธิบาย ไม่ใช่ลำดับประกอบที่ตรวจรับ

## 3. UI
คงการเลือกสินค้า หมุน/ซูม มุมหน้า/ข้าง/บน แยก–ประกอบ เลือกชิ้นส่วน ข้อมูลวัสดุ สีตัวอย่าง โครงเส้น PNG export และมือถือ
กล้องต้องเห็นชิ้นส่วนครบเมื่อแยก และปรับเมื่อหน้าจอเปลี่ยนขนาด

## 4. ตรวจงาน
- npm run check และ npm run build ผ่าน
- เปิด browser จริง ตรวจ runtime errors และภาพทุกโมเดล
- แยกรายงานตรวจกรอบรวมออกจากมิติรายชิ้น
- ทดสอบเลือกสินค้า แยก/ประกอบ เลือกชิ้นส่วน มุมกล้อง สี คืนค่า และหน้าจอ 390 px
- เก็บภาพตรวจงานและผลทดสอบ พร้อมบอกสิ่งที่ยังไม่ทราบ
- แบบต้นฉบับอยู่ private-inputs ห้ามเผยแพร่โดยไม่ได้รับอนุญาต

## 5. ส่งมอบ
โค้ดรันได้ + dimension record + assumptions + ภาพและผลตรวจ + README ที่ใช้ทำต่อได้
